# 牛牛爱学习

牛牛爱学习（by Mr.Chen）是一款面向考试星（`exam.kaoshixing.com`）的非官方 Chrome 扩展。它读取当前课程的章节列表，通过平台接口自动提交未完成章节的学习进度，并在扩展弹窗中显示处理进度和执行日志。支持视频、音频和文档。

## 安装

1. 下载或克隆本仓库。也可以下载并解压 [牛牛爱学习.zip](./牛牛爱学习.zip)。
2. 在 Chrome 地址栏打开 `chrome://extensions/`，开启 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择直接包含 `manifest.json` 的文件夹。
4. 从 Chrome 工具栏的扩展菜单打开 **牛牛爱学习**。可以将它固定到工具栏。

仓库源码可直接加载，无需安装依赖或构建。参见 [Chrome 官方安装说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。

## 使用

1. 登录考试星，进入 **学习项目**，打开一门课程并点开任一视频，进入播放页。
2. 等待章节列表加载完成，再打开扩展弹窗，点击 **开始学习**。
3. 在弹窗中查看处理进度和日志。需要中途结束时，点击 **停止学习**。
4. 任务结束后，刷新课程页面查看平台记录。处理下一门课时，进入该课程的播放页并重新启动。

点击弹窗右上角的 **设置** 可选择快速、均衡或慢速，默认使用均衡。扩展会在本地保存所选模式。

## 常见问题

- **未检测到数据或未获取到文件列表**：确认当前标签页是课程视频播放页，并等待章节列表加载完成后再试。
- **未获取完整接口参数**：确认考试星仍处于登录状态，刷新课程页面后重试。
- **进度条到达 100%，但仍有章节未完成**：进度条统计已处理章节，包含提交失败的章节。查看日志中的成功和失败数量，并以课程页面显示的记录为准。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| [manifest.json](./manifest.json) | Manifest V3 配置，声明弹窗、后台脚本和权限 |
| [popup.html](./popup.html) | 弹窗、进度条、日志和速度设置界面 |
| [popup.js](./popup.js) | 读取章节、提交学习进度和控制任务 |
| [bg.js](./bg.js) | 后台 Service Worker，记录安装日志和收到的日志消息 |

## 使用声明

扩展使用当前考试星登录会话向平台提交学习记录，会影响账号的课程进度。请在获得授权且符合平台规则的环境中使用。本项目仅用于学习交流，具体说明见 [DISCLAIMER.txt](./DISCLAIMER.txt)。
